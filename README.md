## &nbsp;👋&nbsp; About Me

I'm a full-stack web developer from Indonesia 🇮🇩 who likes building things that are **clean, functional, and actually useful**. My comfort zone is the **Laravel + JavaScript** ecosystem, and I enjoy taking a project all the way — from database schema to polished UI. Lately I've been weaving **AI features** into web apps and getting curious about **web security**.

```yaml
location:   Indonesia 🇮🇩
focus:      Full-Stack Web Development (Laravel · React)
currently:  building real-world apps & exploring AI integration
learning:   system design + clean architecture
mindset:    "ship it, then make it better"
```

- 🔭 &nbsp;Building full-stack apps with **Laravel 12** & **React**
- 🤖 &nbsp;Exploring **AI integration** in web apps via the **Google Gemini API**
- 🛡️ &nbsp;Curious about **web security** & incident response (CSIRT)
- 🌱 &nbsp;Leveling up in **system design** and writing maintainable code
- 💬 &nbsp;Ask me about **Laravel, PHP, Tailwind**, or **building an MVP from scratch**

## &nbsp;🚀&nbsp; Featured Projects

### 🏠 KosMutiara27 — Boarding-House Management System
A full-stack **Laravel** application that digitizes boarding-house (kos) operations end to end. Built with **multi-role access** (Admin · Owner · Tenant), room & tenant management, payment verification, **PDF/Excel reporting**, and an **AI assistant** powered by Google Gemini for data analysis.

`Laravel 12` · `PHP 8.2` · `Tailwind CSS` · `Alpine.js` · `MySQL` · `Gemini API` · `DomPDF` · `PhpSpreadsheet`

[**→ View Showcase**](https://github.com/adzkiyaqarina/kos-mutiara27-showcase) · [**Live Demo**](https://mutiara27.eightspace.cloud)

<br/>

### 💼 qar-portfolio — Personal Developer Portfolio
A modern, responsive portfolio built with **React + Vite** and backed by **Supabase**, shipped through a **CI/CD pipeline** via GitHub Actions.

`React` · `Vite` · `Supabase` · `JavaScript` · `CSS`

[**→ View Repository**](https://github.com/adzkiyaqarina/qar-portfolio) · [**Live Site**](https://adzkiyaqarinas.com)

<br/>

### 🛡️ WSKT CSIRT — Security Incident Response Platform
A **CSIRT** (Computer Security Incident Response Team) web platform for handling and reporting security incidents — a collaborative project built on the Laravel stack.

`Laravel` · `Blade` · `PHP`

[**→ View Repository**](https://github.com/adzkiyaqarina/wskt_csirt)
